
# e-plantShopping

## Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux based shopping cart application for buying house plants online.

### Features
- Landing page with Get Started button
- Product listing page with plant categories
- Shopping cart using Redux Toolkit
- Add to Cart functionality
- Increase and decrease quantity of items
- Remove items from cart
- Dynamic cart item counter
- Checkout button
- Continue shopping option

### Technologies Used
- React
- Redux Toolkit
- React Router DOM
- CSS
